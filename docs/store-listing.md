## Store name

> Naming rationale: the brand stays short and pronounceable (from
> *clarify*); the descriptor is a general capability pairing ("Writing &
> Editing") that matches how users search, with audience scenarios carried
> by the description rather than the name. The "for Word" compatibility
> suffix is the compliant pattern — store policy forbids branding the
> product as "Word"/"Office" itself. The name is env-overridable via
> `DISPLAY_NAME` (see `.env.example`), so a rename is a one-line change.

## Full description (EN — primary store language)

**Your document. Your call. Nothing changes without your approval.**

You know the scene: a draft due tomorrow — a thesis chapter, a contract, a
report. Vague paragraphs, inconsistent terms, formatting chaos from five
rounds of edits — and every fix must be traceable, because someone senior
is going to read the redlines.

Claric puts an AI writing & editing assistant **inside Word** that works
the way careful people actually work: **you ask in plain language (English
or 中文), it proposes, you decide.**

### For academic writing 🎓

- 🖊️ **"Polish this paragraph."** Select any passage of your paper and get
  clearer, more formal academic English — shown as a before/after diff,
  applied as word-level **tracked changes** your supervisor can accept or
  reject, exactly like a human editor's markup.
- 🔁 **"Revise this chapter based on my advisor's comments."** Digest the
  tracked changes and margin notes, draft the revisions, and stage each one
  as a reviewable edit.
- 💬 **"Summarize all the reviewer comments in this document."** Every
  margin note and review comment distilled into one actionable list.
- 🧹 **Thesis hygiene in one line:** "Delete the empty paragraphs," "Make
  all headings consistent," "Insert a 4×3 table with the experiment
  schedule" — no more twenty-minute squinting sessions.

### For contracts & legal ⚖️

- 🔍 **"Check this whole contract for risky terms."** Claric reads the
  document section by section, leaves margin comments where it sees
  problems, and proposes fixes — each one a separate review card.
- ✍️ Every proposed amendment lands as a **native redline**, so opposing
  counsel and partners see a normal, reviewable markup.

### For everyday documents 📄

- 🎨 **"Design an illustration for the cover." / "Center all the
  headings." / "Continue writing from here."** Formatting, figures, and
  first drafts — all on request.
- 📊 **"Add a 4×3 table with the project milestones."** Tables appear as a
  preview first — no dragging grid handles, no misaligned cells.

### Nothing is applied until YOU approve it

Every AI suggestion lands as a **proposal card** in a chat panel beside
your document: the before/after diff, one checkbox per change, a button to
jump to the exact spot in the document. Tick what you want, apply — Word
records it all as **native tracked changes**. Reject the rest with one
click. Your document is never silently rewritten.

### Your AI. Your rules.

Claric doesn't lock you into one AI vendor — you connect the model:

- 🔒 **Run AI locally** (Ollama, vLLM) so unpublished research and
  confidential contracts never leave your computer.
- ☁️ **Or use a cloud model** — DeepSeek, Zhipu GLM, Moonshot Kimi,
  MiniMax, or any OpenAI-compatible API — with your own key. You're in
  control of what's sent and where.

**Try it now:** open any document, select a paragraph, and type *"polish
this selection."*

## 中文参考版（如提交多语言 listing）

**你的文档，你说了算——AI 不经你确认，绝不动一个字。**

想象一下：明天要交的稿子——可能是学位论文的一章、一份合同、一份报告。
段落含糊、术语不一、改了五轮的格式一团乱——而且每一处修改都必须留痕，
因为导师（或合伙人）要看修订记录。

Claric 是住在 Word 里的 AI 写作与编辑助手，按严谨的人的方式工作：
**你用大白话下指令（中文英文都行），它出方案，你拍板。**

### 学术写作 🎓

- 🖊️ **"润色这段话"**——选中论文里的任何一段，得到更清晰、更正式的学术
  英语表达，以逐词修订（tracked changes）方式落地——和导师的红笔批注一模一样，
  可逐条接受或拒绝。
- 🔁 **"按导师的批注修改这一章"**——通读批注与修订，起草修改稿，
  每处修改单独一张确认卡。
- 💬 **"总结文档里所有审稿意见"**——几十条批注，一分钟变成一份可执行的修改清单。
- 🧹 **一句话搞定论文琐事**："删除多余空段"、"所有标题格式统一"、
  "插入一张 4×3 的实验安排表格"。

### 合同与法律 ⚖️

- 🔍 **"检查整份合同的风险条款"**——分节通读全文，在风险处加批注，并给出修改建议。
- ✍️ 所有修改以**原生红线（redline）**落地，对方律师看到的和你自己看到的一样。

### 日常文档 📄

- 🎨 **"给封面画一张插图" / "所有标题居中" / "从这里继续写"**——排版、配图、续写，一句话的事。
- 📊 **"插入一张 4×3 的项目里程碑表格"**——先看预览再插入，不再手动拖格。

**所有修改先审后用**：每条 AI 建议都是一张提案卡——改前改后对比、逐条勾选、
一键定位到原文；应用后全部是 Word 原生修订。文档永远不会被悄悄改写。

**AI 你说了算（BYOK）**：本地模型（Ollama / vLLM）让未发表的研究和机密合同
不出你的电脑；或填入自己的 key 使用 DeepSeek、智谱 GLM、Kimi、MiniMax 等云端模型。

现在就试：打开任意文档，选中一段话，输入"润色这段话"。

## Reviewer notes (paste into Partner Center "Notes for certification")

> This add-in is **bring-your-own-key (BYOK)**: it connects to the model the
> user configures. To review core functionality, open Settings → choose
> **DeepSeek** (or any OpenAI-compatible provider) → paste an API key → then:
>
> 1. Select a paragraph, type "polish this selection" → a proposal card with
>    a before/after diff appears; Apply inserts **native tracked changes**.
> 2. Type "summarize this document's comments" to exercise whole-document
>    extraction.
> 3. Type "insert a 3×3 table" to exercise table creation (deterministic,
>    no LLM needed).
>
> On Word for the web, structural operations (table insert/row ops)
> intentionally apply **untracked with an explicit warning** — the host does
> not support structural revisions. All text edits remain tracked.
> Privacy disclosures: document text is sent only to the user-configured LLM
> endpoint; API keys are stored in browser localStorage of the add-in origin.
> See the privacy policy linked in the listing.
